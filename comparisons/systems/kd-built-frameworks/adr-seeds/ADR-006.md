**Context.** LoomWarp has `fractal/STRATEGIST-loomwarp.md`, but nothing states which of its sections may be held across sessions and which must be re-read, and nothing states what wins when the document disagrees with the live repository.

**Decision.** The Tier-0 document carries a `§0` reading-rules table that declares (a) which sections are cache-warm and which are volatile, and (b) an explicit source-of-truth precedence: **live-state pointer > this document > git history**. Its current-state section is pointer-only — it names where live state lives and does not restate it.

**Consequences.** Agents stop treating a stale strategy document as authoritative over the working tree. The document's own status section cannot fossilize, because it contains no status.

**Failure of the simpler design.** The predecessor's previous revision restated live status inline; it went stale and agents acted on it. The revision that replaced it records the failure in its own header. This is an observed failure, not a hypothetical one.
