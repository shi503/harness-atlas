**Context.** A dispatching agent that reads implementation detail loses the ability to hold an epic and sequence it. Nothing currently stops LoomWarp's architect from doing so.

**Decision.** The orchestrator's context window is for orchestration. It keeps four responsibilities — decomposition authoring, workstream PRD authoring, handoff evaluation, escalation — and delegates anything requiring more than 3 steps or touching more than 2 files or modules.

**Consequences.** A cheap, mechanical delegation test replaces per-task judgement. The orchestrator stays able to reason about the whole graph.

**Failure of the simpler design.** Without a threshold the orchestrator absorbs work incrementally, and the point at which it can no longer sequence arrives without warning — there is no signal, because the symptom is degraded sequencing rather than an error.
