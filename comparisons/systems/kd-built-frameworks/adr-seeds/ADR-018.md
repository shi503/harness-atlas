**Context.** A knowledge base accumulates statements that read like decisions. Without a bright line, agents cite prose as though it were ratified.

**Decision.** Entries are written only through the promotion skill or the store CLI. Direct file writes into a decision-log directory are a violation, **and so is treating knowledge-base prose as a decision**. A decision has an ID, an owner, a RACI block and an audit trail, or it is not a decision. Promotion is a visible ceremony that converts one into the other.

**Consequences.** The boundary between captured thinking and ratified decision stays legible. The audit trail stays complete because there is no path around it.

**Failure of the simpler design.** The predecessor tracks this as a named failure mode with both clauses, which means both were observed. The second clause is the one that actually bites.
