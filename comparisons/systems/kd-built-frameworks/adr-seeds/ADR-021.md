**Context.** An agent reaches for personal memory because it is auto-loaded every session and zero-friction to write. That store is per-user, outside git, and invisible to every teammate's agent, so team-relevant facts written there become a shadow source of truth.

**Decision.** One question routes every fact: **would another teammate's agent need this to be correct about the project?** No means personal memory — user identity, preferences, how to work with them. Yes means team knowledge, or the decision store if it is change-managed with named ownership. The moment a memory turns out to be team-relevant it is promoted and the personal copy reduces to a pointer. On conflict, the ledger wins.

**Consequences.** Shadow sources of truth stop forming. Smell test for review: a project-typed personal memory is almost always a promotion signal.

**Failure of the simpler design.** No routing rule means the destination is chosen by whichever store is easiest to write, which is always the wrong one.
