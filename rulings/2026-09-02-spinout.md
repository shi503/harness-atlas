# Ruling — the spin-out

**What retired, and why.** The harness framework cannot grade LoomWarp honestly while it lives
inside LoomWarp. Two artifacts had fused — a maturity spectrum and a primitive catalog — and the
shape was buried in a 500-line guide. The framework now lives here as a wiki of short linked pages,
with LoomWarp as one peer column. The full argument is the handoff:
[`archive/sessions/NEXT-STEPS-framework-spinout.md`](../archive/sessions/NEXT-STEPS-framework-spinout.md).

**Source.** `loomwarp-team-system` at commit `de3ce64` (the checkpoint taken before the copy, so the
tree was clean per that repo's ISSUE-008), path `projects/loomwarp/`. Decided in the session at
https://claude.ai/code/session_013hLaVYWX5To3uSA7iTtz9T with KD.

**Method.** Copied, not moved, and not history-filtered — KD's call. The source files stay in place
marked `status: SUPERSEDED` with a `superseded_by:` pointer to their path here. This file and the
rewrite script are the provenance chain: `scripts/rewrite-paths.mjs` holds the exact old→new table
and was run once on a fresh copy; 1,376 relative links were re-relativised, 78 links to files that
stayed with LoomWarp became absolute GitHub links, 45 frontmatter paths were re-pointed, 0 were
left unmapped, and `scripts/check-doc-links.mjs` passes.
