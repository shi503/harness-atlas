**Context.** An agent that keeps resubmitting against a failing gate burns budget without converging, and an escalation that only reports failure moves the problem without moving the decision.

**Decision.** Two attempts maximum. First failure returns specific feedback at `file:line` and the worker resubmits. Second failure stops the loop and escalates with three things: what failed, what was tried, and **a recommendation**. Standing escalation triggers: any workstream scoping out-of-mandate work, any scope change to a gated workstream, any newly discovered failure mode.

**Consequences.** Failure cost is bounded and predictable. The escalating agent is required to have formed a view.

**Failure of the simpler design.** Unbounded retry against a subjective gate is the observed budget-overrun pattern; one recorded run in this repository overran its cap by 6.5x with no terminal signal.
