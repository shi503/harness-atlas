**Context.** ADR-006 through ADR-024 describe contracts. In the system they are drawn from, **none of them bind** — there is no settings file, no hook, and no validator anywhere in that repository. Its guardrails are prose a model may ignore, and the evidence they were followed is 81 handoffs authored by the one person who wrote the rules.

**Decision.** No contract in this set is considered adopted until a mechanical check exists at a point the model cannot reach. Minimum pairings:

| Contract | Enforcement |
|---|---|
| PRD file manifest (ADR-009) | Pre-dispatch check: reject a PRD with no manifest; post-run diff-scope check against it |
| Handoff evidence table (ADR-013) | Reject a handoff missing a gate table or an explicit not-completed section |
| Heartbeat format (ADR-014) | Parse on write; malformed block fails loudly |
| Single ledger write path (ADR-018) | Pre-commit hook rejecting unmediated writes into a decision-log directory |
| Skill invocation discipline (ADR-022) | Package validation in CI |

**Consequences.** The policy function moves off its floor. Contracts survive an operator who did not write them.

**Failure of the simpler design.** Prose-only enforcement is exactly what produced the predecessor's ceiling — and, independently, this repository's own Stage-1 grade on the same function. Two systems, same omission, same result. The harness now supplies hooks with permission decisions, managed settings, and parameter-level tool matchers, so this is a configuration change rather than a build.
