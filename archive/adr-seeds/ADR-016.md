**Context.** LoomWarp already runs the storage layer this decision describes (see ADR-002) without having recorded the invariant that makes it correct.

**Decision.** Markdown files are the record. The SQLite index is derived, may be deleted, and rebuilds losslessly. A consistency check compares every indexed row to its file by content hash and reports drift in both directions — indexed-but-missing and on-disk-but-unindexed.

**Consequences.** The decision store survives the tool that writes it. Index corruption is recoverable rather than fatal.

**Failure of the simpler design.** A database of record with markdown exports produces a log whose readability depends on a running service, and an export that drifts from the record with no way to detect it.
