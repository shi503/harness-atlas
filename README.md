# harness-atlas

Harness solutions are a spectrum indexed to team maturity, the way Agile ranges from lean startup to
SAFe. Solution spaces are individual, the way teams have different IDE preferences. Being able to
name the layers and their interactions lets us design the connections better.

This repo is the instrument: a fixed list of components, a way to tear any harness down into the
primitives it actually ships, and a grid that scores them side by side so the shape of harnesses can
be tracked as they develop.

Start at [`index.md`](index.md).
