One page per harness, built the same way every time

Thirty secondsThe cardAltitude, primitives, what it refuses, where state lives, a coverage count.
The pictureSystem mapThe vendor's own diagram, redrawn — plus its signature workflows.
The receipts33 rowsOne mark each: ● named primitive · ◐ present · ○ absent.

Absence is recorded, never inferred — every ○ names the pages that were checked. Vendor's words only in a primitives table, verbatim and dated. And I scored my own harness by the same rules. It came out worst on the sheet.
